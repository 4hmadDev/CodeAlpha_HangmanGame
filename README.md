# CodeAlpha Hangman Game 🎮

## About the Project

This is a simple **Hangman Game** that I created as part of my **CodeAlpha Internship**.

In this game, the computer randomly selects a word from a list, and the player has to guess the word one letter at a time.

## How the Game Works

When the game starts, a random word is selected from the list.

The player has **6 attempts** to guess the word.
